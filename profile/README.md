# Face Analysis

Free, open face measurement tools and data from [thefaceanalysis.com](https://thefaceanalysis.com): a 478-point
landmarker that runs in the visitor's browser, with the numbers, thresholds and limits published.

## For websites
- [`thefaceanalysis-embed`](https://www.npmjs.com/package/thefaceanalysis-embed): a free face shape finder for your own page (web component + React). [Embed guide](https://thefaceanalysis.com/embed)

## For data and research
- [`thefaceanalysis-data`](https://www.npmjs.com/package/thefaceanalysis-data): fWHR, midface ratio, symmetry, canthal tilt and pupillary distance percentiles from 102 faces, plus face/eye/lip/nose types and every threshold. CC BY 4.0. [Statistics page](https://thefaceanalysis.com/face-measurement-statistics) · [Methodology](https://thefaceanalysis.com/methodology)

## For AI assistants
- [`thefaceanalysis-mcp`](https://www.npmjs.com/package/thefaceanalysis-mcp): an MCP server for Claude, Cursor, ChatGPT and any MCP client. Hosted at `https://mcp.thefaceanalysis.com/mcp`, or run it locally with `npx -y thefaceanalysis-mcp`. [Setup](https://thefaceanalysis.com/mcp)

## How we publish numbers
One research set (Face Research Lab London Set, 102 faces), measured by the same code the site runs. We publish the limits next to the data: the numbers describe these faces, not a population, and our 1-10 score did not predict human ratings of the same faces. Changes to thresholds or formulas are dated in the [changelog](https://thefaceanalysis.com/changelog).
